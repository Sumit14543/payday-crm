================================================================================
    PAYDAY LOAN CRM - HOW TO RUN ON LOCALHOST
================================================================================

📌 PREREQUISITES
----------------
1. Install Node.js (version 16 or higher)
   Download from: https://nodejs.org/
   
2. Verify installation by opening terminal/command prompt and typing:
   node --version
   npm --version

================================================================================

🚀 METHOD 1: DEVELOPMENT MODE (Recommended for Testing)
--------------------------------------------------------

Step 1: Open Terminal/Command Prompt
   - Windows: Press Win + R, type "cmd", press Enter
   - Mac: Press Cmd + Space, type "terminal", press Enter
   - Linux: Press Ctrl + Alt + T

Step 2: Navigate to Project Folder
   cd path/to/your/project
   (Example: cd C:\Users\YourName\Downloads\payday-loan-crm)

Step 3: Install Dependencies (First Time Only)
   npm install
   
   Wait 2-3 minutes for installation to complete.

Step 4: Start Development Server
   npm run dev

Step 5: Open in Browser
   The terminal will show a URL like:
   
   ➜  Local:   http://localhost:5173/
   
   Open your browser and go to: http://localhost:5173

✅ DONE! Your CRM application is now running!

================================================================================

🏭 METHOD 2: PRODUCTION MODE (For Deployment)
----------------------------------------------

Step 1-3: Same as Method 1

Step 4: Build the Application
   npm run build
   
   This creates optimized files in the 'dist' folder.

Step 5: Start Production Server
   npm start

Step 6: Open in Browser
   Open your browser and go to: http://localhost:3000

✅ DONE! Your production server is now running!

🐛 TROUBLESHOOTING
------------------

Problem: "Port 5173 is already in use"
Solution: Close other applications or use different port:
   PORT=5174 npm run dev

Problem: "npm: command not found"
Solution: Install Node.js from https://nodejs.org/

Problem: "Cannot find module"
Solution: Delete node_modules folder and run:
   npm install

Problem: Blank page in browser
Solution: 
   1. Check terminal for errors
   2. Press F12 in browser to see console errors
   3. Make sure server is running

Problem: Changes not showing
Solution: 
   1. Save your file
   2. Wait 2-3 seconds for auto-reload
   3. Refresh browser (Ctrl + F5 or Cmd + Shift + R)
