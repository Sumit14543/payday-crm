🚀 HOW TO RUN YOUR APPLICATION
================================================================================

STEP 1: Install Dependencies (First Time Only)
-----------------------------------------------
Open terminal in the project folder and run:

    npm install

Wait 2-3 minutes for installation.


STEP 2: Start the Application
------------------------------
Run one of these commands:

For Development (Recommended):
    npm run dev
    
Then open: http://localhost:5173


For Production:
    npm run build
    npm start
    
Then open: http://localhost:3000


STEP 3: Access the Application
-------------------------------
Open your browser and visit the URL from Step 2.

You should see the PayDay Loan CRM dashboard!

💡 QUICK TIPS
================================================================================

1. Development vs Production:
   - Use "npm run dev" for development (faster, auto-reload)
   - Use "npm run build && npm start" for production

2. Making Changes:
   - Edit files in src/ folder
   - Save the file
   - Browser auto-refreshes (in dev mode)

3. Stopping the Server:
   - Press Ctrl + C in the terminal

4. Checking Logs:
   - Watch the terminal for logs and errors
   - Press F12 in browser for console errors

================================================================================
🐛 TROUBLESHOOTING
================================================================================

Problem: Port already in use
Solution: Change port: PORT=3001 npm start

Problem: npm not found
Solution: Install Node.js from nodejs.org

Problem: Blank page
Solution: Check terminal for errors, ensure server is running

Problem: Changes not showing
Solution: Save file, wait 2-3 seconds, refresh browser

For more help, read: HOW_TO_RUN_ON_LOCALHOST.txt
